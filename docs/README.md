# docs/

The caller's guide and the module map: how to use `d-dolar` and, for anyone
changing it, which module holds what. Nothing here yet — written once the
package has a public surface worth documenting.

If a document is useful for *using* or *changing* d-dolar, it belongs here,
committed with the code. Notes about how the library came to be — plans,
analyses, reviews — belong in the private sibling `../d-dolar-notes` instead.
